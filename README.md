# 此刻 · TOTP 计算器

此刻（`totp-now`）是一个在浏览器内临时生成动态验证码的工具。输入 Base32 绑定密钥，即可获取当前的 6 位 TOTP 验证码。验证码每 30 秒更新，页面显示剩余时间，并支持一键复制。

## 本地运行

安装 Python 3 后，在仓库根目录运行：

```bash
python3 -m http.server 8000 --bind 127.0.0.1
```

打开 [http://127.0.0.1:8000/](http://127.0.0.1:8000/)。粘贴绑定密钥后，页面会自动生成验证码。删空密钥输入框即可清除当前验证码。

## 计算与隐私

计算使用浏览器的 Web Crypto API，参数为 HMAC-SHA1、30 秒周期和 6 位输出。密钥只在当前页面内处理，页面不会上传密钥或将其写入持久化存储。

项目无需构建或业务后端。部署时，用 HTTPS 静态托管 `index.html`、`styles.css` 和 `src/`，并保留它们的相对路径。

## 项目结构

- `index.html`、`styles.css` — 页面结构和样式
- `src/config.js` — 配置与校验
- `src/totp.js` — Base32 解码与 TOTP 计算
- `src/app.js` — 输入、倒计时和复制交互
